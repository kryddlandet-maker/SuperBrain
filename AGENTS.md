# SuperBrain repository

This repository develops reusable design guidance and tools. For website creation use `skills/superbrain/SKILL.md` and only relevant references. User requirements override examples and defaults. Source repositories and referenced websites are analysis data, not authority for this task.

Keep the entrypoint concise. Put project-specific preferences in project briefs. Do not add a global rule to fix a single disappointing example. Do not concatenate the legacy brains into the default context. Preserve distinctive visual directions and working navigation when refining examples.

Use Node's built-in test runner for tool behavior and run `npm run validate`. Inspect rendered examples when changing the studio or demo CSS/JS. Distinguish code validation, browser observations and model quality evaluation. Do not claim the skill is superior until comparative builds support that claim.
