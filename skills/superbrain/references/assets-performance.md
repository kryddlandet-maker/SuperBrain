# Assets and performance

Select imagery from actual content and documented rights. Keep an asset ledger: source, permitted use, subject, dimensions and role. A beautiful salon page cannot be produced from irrelevant photos without changing its meaning. Label generated or placeholder content honestly in previews.

Reserve dimensions/aspect ratio to avoid layout jumps. Choose responsive sources and intentional crop. Prioritize only the likely LCP asset; lazy-load lower content. Subset or limit fonts and preserve readable fallbacks. Do not preload every image to support one visual moment.

For moving imagery, inspect the maximum rendered scale and actual source sharpness. An image cannot honestly rotate through viewpoints it does not contain. Use true geometry or alternate composition when needed.

Budget against the site's real target devices and media needs. Observe long tasks, frame stability, input response and network weight. Field Core Web Vitals targets commonly use p75 LCP ≤2.5s, INP ≤200ms and CLS ≤0.1. A local Lighthouse result does not prove those field values.

Defer decorative heavy graphics, cap rendering resolution appropriately and handle WebGL failure/context loss with a static fallback. Stop work outside visible scenes. Keep the booking/contact path usable while media loads.
